# Evidence Table

Master claim → source verification ledger. Consolidated 2026-09-03 from four
parallel research passes (concentration/structure, imports, COOL timeline,
price transmission); rows below are reproduced verbatim from each fork's
sub-table (`Evidence_Table_Concentration.md`, `Evidence_Table_Imports.md`,
`Evidence_Table_COOL.md`, `Evidence_Table_PriceTransmission.md` — kept as
detailed backing, not superseded). Every load-bearing empirical claim used
elsewhere in this project (NOTES, LITERATURE, ANALYSIS, STUDY* memos,
eventually MANUSCRIPT) should trace back to a row here. Add new rows at the
bottom of the relevant section; do not delete superseded rows — mark them
superseded and explain why in Notes.

Verification status values: `Verified (primary)`, `Verified (secondary,
traced to primary)`, `Could not verify`, `Contradicted by other source`,
`Pending`.
