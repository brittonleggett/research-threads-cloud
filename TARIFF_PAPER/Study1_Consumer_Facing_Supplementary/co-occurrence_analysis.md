# Co-occurrence Analysis — Attribution Frame × Cost-Response (Supplementary Sample)

**Important caveat up front:** N=6, found via opportunistic keyword search
(not systematic/random sampling), spanning DTC brands, one B2B/industrial
case, and one large-platform case (Amazon). This is **directional
motivation only** — it is explicitly NOT causal evidence and cannot resolve
H3 (only Study 2's actual experimental manipulation can do that). Treat this
the same way a few illustrative anecdotes would be treated in a grant
proposal's motivation section, not as a pilot dataset.

## The six artifacts, tagged

| Artifact | Attribution Frame | Cost-Response |
|---|---|---|
| KDAR (Hot Max) | Explicit | Restraint signal (hedged, not quantified) |
| Amazon Haul (reversed) | Would-be explicit → reverted to silent | N/A (disclosure question, not pass-through) |
| Dame | Explicit (maximal — checkout line item) | Partial absorption (quantified: "$5 doesn't cover all of it") |
| Honeywell | Explicit | Full pass-through (bounded %, time-limited) |
| Labucq | Explicit-but-general | Full pass-through (no absorption claim) |

(Amazon Haul excluded from the pass-through tally — it's a disclosure-format
case, not a cost-response case.)

## What the pattern shows, honestly

Of the 4 artifacts that have a clean Attribution × Cost-Response pairing:
- **3 of 4 pair explicit attribution with something other than full
  absorption** (KDAR = restraint-but-hedged, Dame = partial/quantified,
  Honeywell = full pass-through, Labucq = full pass-through).
- **Zero artifacts in this small sample show a full-absorption promise**
  paired with explicit attribution — consistent with the locked corpus's own
  finding that full-absorption promises are rare (Chipotle is the *only*
  clean case there too, and it's from a full year earlier).
- Explicit attribution shows up **regardless of** whether the company is
  absorbing some cost (Dame, KDAR) or passing the full amount through
  (Honeywell, Labucq) — in this small sample, **explicit attribution appears
  to be the norm across the board**, not something reserved for one
  cost-response strategy over the other.

**What this suggests for H3, with the limitation stated plainly again:**
This sample is too small and non-random to "lean" confidently toward either
the reinforcing or compensatory direction — explicit attribution shows up
alongside *both* full pass-through (Honeywell, Labucq) and partial absorption
(Dame, KDAR) at roughly similar rates here. If anything, the fact that firms
passing the **full** cost through (Honeywell, Labucq) still bother to name
tariffs explicitly is mildly more consistent with the **compensatory**
story (Claude's 2026-09-08 recommendation to the parent conversation) —
these firms have no absorption signal to lean on, so explicit attribution is
plausibly doing more of the fairness-justification work by itself. But this
is a weak signal from 2 data points, not a resolved question, and should be
described in any write-up as "one small illustrative observation," not
evidence.

## Genuine dead ends worth noting

- **A second real asymmetric-disclosure case (explaining an increase but not
  a later decrease) did not turn up** in this pass — searches for this
  specific pattern returned nothing usable. This is consistent with the
  locked corpus's own framing of GMS as a single, exploratory case: the
  pattern may simply be rare because price *decreases* tied to tariff relief
  are themselves rare and rarely announced with the same fanfare as
  increases.
- **A second real full-absorption-promise case also did not turn up** for
  the same reason Chipotle stands alone in the locked corpus — full
  absorption is apparently uncommon enough in practice that finding a second
  clean, current (2025-2026) example was not possible in this pass without
  much deeper searching than the scope of this supplementary task warranted.
