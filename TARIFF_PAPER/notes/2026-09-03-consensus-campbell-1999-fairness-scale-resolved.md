## What Consensus found — direct, quote-level

Campbell (1999) ran two experimental studies. **Study 1** measured
perceived fairness with a **single-item, 7-point bipolar scale**: 1 = "very
fair," 7 = "very unfair." **Study 2** added a second item — agreement with
the statement **"This price is not fair"** (1 = "strongly agree," 7 =
"strongly disagree," reverse-scored) — averaged with the first bipolar item
to form a **two-item Perceived Fairness scale, r = .84, p < .0001**.

| Item | Wording | Anchors |
|---|---|---|
| Fairness (both studies) | Bipolar single item | 1 = "very fair," 7 = "very unfair" |
| Fairness (Study 2, 2nd item) | "This price is not fair" | 1 = "strongly agree," 7 = "strongly disagree" — **reverse-scored** before averaging with item 1 |

**Recommendation: use the Study 2 two-item version** (both items, averaged,
with the second reverse-scored) — it has a reported reliability coefficient
(r = .84) the single-item Study 1 version doesn't, and this project's design
is closer to Study 2's structure (motive + reputation manipulation) than
Study 1's simpler design.

## Bonus finding — explains the earlier "unfair/unacceptable/unreasonable"
lead

The 3-item "unfair/fair," "unreasonable/reasonable," "wrong/right" wording
that earlier searches kept surfacing in connection with "Campbell" is real,
but it's **not the 1999 original** — Consensus traces it to **Campbell's
2007 follow-up paper**, and a 2025 "moral harm model" paper cites that 2007
version specifically (not 1999) when using this 3-item wording. So there
are now two legitimately citable Campbell-lineage fairness scales:
1. **Campbell (1999) original** — 2-item, verified above, r = .84. This is
   what's recommended for this project, since it's the actual foundational
   citation this paper's theory section already leans on.
2. Campbell (2007)'s later 3-item version — a legitimate alternative if a
   3-item scale is preferred, but not verified with the same quote-level
   confidence this pass, and would need its own citation (2007, not 1999).
