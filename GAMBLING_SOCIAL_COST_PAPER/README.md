# Gambling Social Cost Paper

## Project purpose
Investigate whether state tax revenue from legalized (especially mobile/online) sports betting compensates for the measurable financial and social costs of its expansion — treating the net effect as an empirical question, not an assumed conclusion in either direction.

## Central question
What is the net public-policy effect of legalized sports betting when state fiscal benefits are evaluated alongside measurable consumer and social costs? See the original kickoff brief for the full set of subsidiary questions (archived at `notes/2026-09-04-original-kickoff-brief.md`).

## Working contribution
The literature audit found the literal "monetized net-benefit calculation" version of this question already partially occupied by a working paper (McCarthy, Taylor et al., UMD Smith/SMU/UCSD) using proprietary transaction data this project cannot access. The recommended working contribution instead is a **state fiscal-dependence → consumer-protection-policy / consumer-vulnerability** design: does a state becoming more fiscally reliant on sports-betting revenue predict weaker consumer-protection regulation and worse outcomes for financially vulnerable bettors? This is a genuinely under-served angle (see `literature/literature_map.md` Category F) and a strong fit for the target venue. See `research_design/candidate_designs.md` for the full design comparison and `PROJECT_STATUS.md` for the formal GO/MODIFY recommendation.
