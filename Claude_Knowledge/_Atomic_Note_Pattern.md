# Note pattern for this folder

Borrowed from Josh Lambert's "Publish Your Priors" — the point is to keep notes cheap enough to actually write, and structured enough that an AI agent can compare/act on them later without you re-explaining context.

**Rules:**
- One screen max. If it needs more, it's a project file, not a knowledge-base note — move it to the relevant project folder instead.
- Structure: a claim/point, then the reasoning, then any open question left dangling.
- Flag open questions explicitly with `**Open question:**` — don't bury them in prose. That's the hook that lets an idea get picked back up later without rereading the whole note.
- No deadline pressure, no "finishing" a note. If it stops being useful, it just sits there — that's fine.
- If a note's content starts feeding a specific project (CCS, tariff, remote work, grooming research, crash course), that's the signal to graduate it into that project's folder and reference it from `Dashboard.md`.
